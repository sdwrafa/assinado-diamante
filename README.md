# Presente de Dia dos Namorados

Mini-site estático com tema romântico vermelho e amarelo, botão-surpresa e animação de um girassol aparecendo.

## Como ver

Abra `index.html` no navegador.

## Como publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie os arquivos desta pasta para o repositório.
3. No GitHub, entre em `Settings` > `Pages`.
4. Em `Build and deployment`, escolha `Deploy from a branch`.
5. Selecione a branch `main` e a pasta `/root`.
6. Salve. O GitHub vai gerar um link público do site.

## Como personalizar

Edite os textos em `index.html`, principalmente:

- `Para o meu amor`
- `Você ilumina meus dias.`
- A mensagem abaixo do título
